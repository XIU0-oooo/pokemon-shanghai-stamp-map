# 上海集章路线图

宝可梦 30 周年上海盛典的免费集章工具。活动时间为 2026 年 11 月 28 日至 2027 年 1 月 3 日，各项活动的开放和截止日期可在日历查看。

[打开集章路线图](https://xiu0-oooo.github.io/shanghai-stamp-map/)

## 使用方法

1. 在「我的集章」勾选已获得的印章。鼠标悬停或手机长按卡片可查看活动简介。
2. 选择想拿的奖励和可出行时段，查看推荐路线。也可选定日期，查看当天可以安排的未集章活动。
3. 在活动日历按打卡、手工或卡牌筛选。点开活动可查看地点、日期和参与说明。

集章进度保存在当前浏览器中。活动安排及预约信息以官方公告为准。[宝可梦中国官方活动公告](https://www.pokemon.cn/tcg/campaign/24854.html)
